# 空间组学算法调研与筛选（科研2）

**负责人**：科研2

## 交付物清单（M1）

- `algorithm_catalog.md`：按图像预处理、细胞分割、转录本分配、空间分析、3D 重构等类别整理的开源算法目录。
- `algorithm_comparison.xlsx`（或 `.csv` / `.md` 表格）：算法输入输出、语言、依赖、GPU/内存需求与部署可行性对比。
- 论文链接、GitHub 仓库地址、版本号与开源许可证清单。

## 算法分流原则

- **通用分析算法**（图像预处理、细胞分割、转录本分配、空间分析等）：移交算法层进入工作流平台接入流程。
- **3D 重构专用算法**（多切片配准、三维重建、网格/点云生成等）：进入路线二评估与验证；若后续需要由 Nextflow 调度，再按 `components/algorithms/_template/` 封装接入。
