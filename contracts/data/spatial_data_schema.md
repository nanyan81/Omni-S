**主责**：数据层成员  
**协同评审**：算法层成员、科研1、科研2、项目负责人  
**目标里程碑**：M2 正式定稿

---

## 1. 核心数据语义约束

1. **明确观测粒度**：每份数据集必须显式标明观测单位（`bin` / `spot` / `cell` / `transcript`），禁止将 `spot` 级数据未经证据直接宣称为单细胞级结论。
2. **对象唯一标识**：保留原始对象 ID 并建立统一 `cell_id` / `object_id`，保证基因表达、空间坐标、细胞分割结果可精确一一关联。
3. **坐标系与单位**：显式记录坐标系来源（像素坐标 vs 物理微米坐标 `µm`）及像素-物理换算比例。
4. **三维条件显式声明**：明确标注是否存在真实 `Z` 坐标或多张连续组织切片，禁止将人为拉伸厚度标记为真实 3D 坐标。

---

## 2. 细胞级分析与 3D 展示的核心字段约定

| 字段名 | 必需 | 说明 |
|---|---|---|
| `sample_id` | 是 | 样本唯一编号 |
| `cell_id` | 是 | 细胞（或观测对象）唯一标识 |
| `coordinates` | 是 | 空间坐标（2D 为 `x, y`；真实 3D 为 `x, y, z`，需注明单位） |
| `gene_expression` | 是 | 与 `cell_id` 对齐的基因表达矩阵（优先采用 `AnnData` / `.h5ad`） |
| `cell_type` | 可选 | 细胞类型注释 |
| `segmentation` | 可选 | 细胞边界多边形或分割掩膜引用 |
