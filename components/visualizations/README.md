# 3D 重构与交互展示（Visualizations / 3D Reconstruction）

**负责人**：科研1 & 科研2

## 第一阶段核心目标

1. **真实三维条件验证**：严格区分“已有真实 X/Y/Z 坐标”、“多张二维切片配准重建”与“单张二维切片展示”，缺乏真实空间依据时不得将人为厚度宣称为真实三维重建。
2. **基因表达映射与颜色筛选**：支持切换基因、按表达值映射颜色、按区间筛选高亮与隐藏未选中对象（依赖 `cell_id`、`coordinates`、`gene_expression` 对齐）。
3. **手势交互（模块解耦）**：
   - `gesture/`：手势识别模块，仅输出缩放/旋转等控制事件；
   - `renderer/`：3D 渲染与相机视角交互模块，响应控制事件，**严禁修改原始空间数据**。

## 解耦原则

- 本模块与 Nextflow 工作流平台保持实现解耦，仅通过标准化数据 Schema 与算法输出文件协作。
