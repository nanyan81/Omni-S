# 基础有效性检查与前置预处理（Data Process）

**负责人**：数据层成员

## 职责范围

1. **基础数据有效性检查（Validators）**：
   - 文件是否存在、能否正常读取；
   - 必需字段是否存在；
   - 数据类型、维度与文件结构是否符合接口约定。
2. **算法前置预处理（Preprocessing）**：
   - 依据算法层提交的 `input_spec.yaml` 与 `preprocessing_requirements.md`，执行经双方确认的外部基础预处理（如图像格式转换、元数据提取）。

## 严格边界

- **不得替算法拆解内部核心计算**：算法内部的归一化、特征提取、图构建等步骤原则上保留在原算法中，只有经算法层确认不会改变算法语义的步骤才放在此处，避免重复预处理。
- **基础格式检查不能替代科学 QC**：科学 QC 由项目负责人在 `components/qc/` 单独负责。
